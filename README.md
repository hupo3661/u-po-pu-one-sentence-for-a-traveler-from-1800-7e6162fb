One sentence, in words a traveler from 1800 would already know, that explains the modern internet: a post office and a road of light. 189 characters, one sentence, no word coined after 1800.

## Run it

```sh
python3 main.py
```

Writes the sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints exactly that sentence to stdout.
